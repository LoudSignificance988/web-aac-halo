Text → Speech (free, browser-based)

Uses the Web Speech API by default. For even higher-quality voices, you can configure an external TTS server (e.g., Coqui TTS) in the "Advanced" section.

Advanced (optional): use a remote TTS server like Coqui

When remote TTS is enabled the page will POST JSON {text, voice, rate, pitch} and expect an audio/* response which will be played and downloadable.
