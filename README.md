# Halo AAC

**Halo AAC** is a free, browser-based **Augmentative and Alternative Communication (AAC)** web app. It helps users communicate by tapping picture cards to build sentences and speaking them aloud using the device's built-in text-to-speech.

## ✨ Features

- 🗂️ **Word Packs** – Choose from Essential, School, Home, or Everything.
- 👤 **Multiple Profiles** – Each profile has its own custom words and settings.
- ➕ **Custom Words** – Add your own words with emojis.
- 🔒 **Parent Portal** – Password-protected settings and vocabulary management.
- ☁️ **Google Sign-In & Cloud Sync** – Sync your words, settings, and profiles across devices.
- 🗣️ **Built-in Text-to-Speech** – Uses your browser's speech synthesis.
- 🎨 **Themes** – Customize colors and backgrounds.
- 📶 **Offline Friendly** – Core communication features work without an internet connection.

## 🚀 Getting Started

### Use Online (Recommended)

Visit Halo AAC in your browser:

**https://loudsignificance988.github.io/web-aac-halo/**

### Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start communicating!

No installation or build process is required.
